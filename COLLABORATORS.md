## Getting Involved

1. **Issues** — Report bugs or request features via [GitHub Issues](https://github.com/bitc0der/RayTree/issues).
2. **Pull Requests** — Fork the repo, create a feature branch, and submit a PR against `main`.
3. **Discussions** — Start a discussion for questions or design proposals.

## Contribution Guidelines

- Follow the conventions documented in `AGENTS.md` and `.editorconfig`.
- All changes must pass `dotnet build RayTree.slnx` and the relevant test suite.
- Zero warnings are acceptable (`TreatWarningsAsErrors=true` is global).
- Write tests for new functionality. See `AGENTS.md` for testing conventions.
- Keep commit messages concise and descriptive.

## Code of Conduct

- Be respectful and constructive in all interactions.
- Review PRs with the intent of improving the code, not criticizing the author.
- Assume good faith in all contributions.
